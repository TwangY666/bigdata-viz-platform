# 大数据可视化平台 · 第一轮改版方案

**打开自己的表，选两个字段，马上看到一张能核对的图。** 这是这次改版要做通的一件事。用户已选定分析工作台方向，常见办公文件优先，兼顾 JSON。视觉稿采用浅色桌面布局，供本轮评审。

## 先看一个真实任务

同学拿到一份订单表，想回答“哪个区域销售额最高”。他打开文件，预览时看到订单号 00123 仍带前导零。进入工作台后，把“区域”放入分组，把“销售额”放入数值，画布立即显示华东 2,000 元、华南 1,000 元。把“求和”改成“平均”，两条柱变成 1,000 元和 500 元。再点“数据明细”，就能对照产生结果的四行记录。

双击同目录的 **02-工作台交互示意.html** 可以体验后半段。示意使用与 **04-区域订单样例.csv** 相同的四笔订单；真实文件导入由 Qoder 在目标仓库实现。

## 原版值得留下什么，哪里最影响使用

审查版本为 main 的 `800f8bf7`。用桌面浏览器打开原版，首页自动展示学生成绩示例，含 120 行、13 个字段；班级筛选、平均分分布、挂科统计等已经很适合讲解一张已知结构的数据表。

| 现状与依据 | 这次的设计决定 |
| --- | --- |
| 首页首先出现示例指标、排序、分箱等控件。打开自己文件的入口位于示例看板工具栏。 | 让“打开数据”成为工作台首要操作，将原目录保留在“示例看板”。分箱等专用控件跟随适用图表。 |
| 文件选择器接受 CSV、TSV、TXT、JSON，按钮提示只列其中三类。上传后调用当前模板的字段匹配，预览会列出未使用的列。 | 导入面板与文件选择器共用支持清单；新增“作为普通表分析”，原模板的匹配能力在示例入口继续使用。 |
| 文本解析先按物理行拆分，带引号且跨行的备注可能被拆成两笔记录；工作簿也会走文本解码路径。 | 文本按完整记录拆分；Excel 走二进制读取。确认前给用户看表头、样本与行数。 |

代码定位见 [页面入口](https://github.com/TwangY666/bigdata-viz-platform/blob/800f8bf7caa045b391e9596775d3d6e724e4f6b7/web/index.html)、[上传与预览](https://github.com/TwangY666/bigdata-viz-platform/blob/800f8bf7caa045b391e9596775d3d6e724e4f6b7/web/assets/js/dash.js#L2050)、[文本解析](https://github.com/TwangY666/bigdata-viz-platform/blob/800f8bf7caa045b391e9596775d3d6e724e4f6b7/web/assets/js/data.js#L981)。

## 页面怎样安排

1. **第一次进入**。顶部“打开数据”，中央提供“打开本地文件”和“试用示例数据”两条路径。返回时能够分辨正在分析的表与内置示例。
2. **导入预览**。显示文件名、工作表、前 10 行和推断类型。多工作表可切换；编号可指定为文本。预览和确认分两步，取消回到原画面。
3. **分析工作台**。顶部显示活动表。左侧切换报表、数据明细和原有示例；中间尽量留给图，标题说清“按什么分组、算什么”；右侧从上至下选择分组、数值、汇总和筛选。字段有文字标签，支持鼠标及键盘选择。
4. **核对结果**。切换明细时沿用当前筛选，回到图表保留配置。筛选后无记录时显示命中 0 行并提供清除筛选；数值缺失按空值处理，在摘要里交代参与计算的条数。

参考 Power BI 的画布、字段面板和工作表选择流程。当前项目把字段和汇总收在同一栏，减少初次分析时来回找控件的次数。[Microsoft Learn 工作台教程](https://learn.microsoft.com/en-us/power-bi/fundamentals/desktop-getting-started)

### 桌面视觉

主画布白底，外围浅灰，正文深灰；深青色用于主操作、选中状态和当前数据系列。数值使用等宽数字，图上直接标数量和单位。1366 像素宽时，左导航约 160 像素，右侧约 280 像素；窗口收窄时先收导航，再把配置放入可打开的侧栏。中文正文建议 14–16 像素，图表标题 20–24 像素。保留现有主题选择，单独检查旧深色模式的控件与图例对比度。

## 第一版的数据范围

| 文件 | 用户能做什么 | 边界 |
| --- | --- | --- |
| CSV、TSV、分隔文本 TXT | 导入办公系统导出的表，自选逗号、制表符或分号；保留引号内的分隔符、换行和双引号 | 识别 UTF-8、GBK 及带 BOM 的 UTF-16；TXT 需有可识别的表格结构 |
| Excel XLSX、XLS | 打开现代或旧版 Excel，选择一张表后预览并分析 | 一次导入一张工作表；公式使用文件中的缓存值，无缓存时提示；加密或损坏文件提供操作建议 |
| JSON | 导入平面对象数组、首行为表头的二维数组，以及 data、rows、records、list 下的记录数组 | 字段取各行键的并集，缺键显示为空；深层对象和数组明确提示处理方式，避免显示成无意义字符串 |

首轮沿用原版单文件 8 MiB 限额，界面写清大小。工作簿还需限制解压后的单元格数，并用真文件测量等待时间。数据库直连、在线 API 和跨表关联可单独排期。

## 分两轮看效果

**先验 UI。** 用附带 CSV 从任意列名生成图，现场切换分组、汇总和明细。核对结果后，再确认画布大小、文字和工具位置。

**再验导入。** 用新旧两类 Excel、中文分隔文本、JSON 分别走完预览与作图；记录打不开时用户看到什么。具体步骤与交付证据见 **03-Qoder任务书.md**。
